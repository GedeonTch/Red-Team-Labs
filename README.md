## About

This repository is a portfolio of hands-on offensive security labs. Each lab reproduces a real attack technique in an isolated environment (host-only network, no production systems) and is documented like a real pentest engagement: scope, methodology, evidence (screenshots), results, and remediation recommendations. The goal is educational — to understand how attacks work in order to better defend against them.

## Legal & Ethical Notice

All techniques demonstrated here were performed in isolated lab environments against machines owned by the author, for educational purposes only. Do not use these techniques against systems you do not own or without explicit written authorization. The author assumes no responsibility for misuse of this information.
